# NilArea · 零域

> Minecraft 模组开发与玩家社区

**NilArea（零域）** 是一个 Minecraft 模组创作团队，致力于为玩家带来丰富的游戏体验。  
我们开发 NeoForge 模组套件，并运营配套 Wiki 与社区论坛。

🔗 官方网站：[nilarea.cn](https://nilarea.cn)

## 🛠 技术栈

- **模组加载器**：NeoForge
- **开发语言**：Java / Kotlin
- **构建工具**：Gradle
- **社区站点**：Nuxt 4 + Cloudflare Workers
- **许可证**：LGPLv3

## 🤝 参与贡献

NilArea 欢迎社区成员通过 **GitHub Issues** 提供反馈、建议或报告问题。

- **报告 Bug 或功能请求**：请在本组织对应的仓库中提交 Issue，并填写清晰的问题描述或建议。
- **参与讨论**：你可以在 Issues 中参与技术讨论，帮助回复其他用户。
- **贡献内容**：普通用户无需提交代码，直接通过网站发布博客、上传资源（需遵守社区规则）即可。
